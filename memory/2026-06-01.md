Took over the Late Night Ricky (LNR) website project from Brian. Spent the day rebuilding the entire site from scratch.

## Key Decisions & Actions

### Design Direction
- Hero: Ricky portrait left-aligned with steel blue gradient overlay, LNR wordmark visible
- M2S-inspired structure but with LNR identity
- Steel blue palette: #1B3A4C, #6B8FAB, #8FA8BE, #A3B5C4, #E3E8ED
- Fonts: Playfair Display (headings) + Inter (body)

### Pages Built
- `index.html` — One-page scrollable landing with all sections
- `about.html` — Separate page with split portrait + bio layout (djcruz style)
- `contact.html` — Kept as separate page for direct access

## Lessons
- When converting separate pages to scroll sections, keep the standalone page files too (Rory wanted both)
- djcruz-style split layouts work well for Contact and About
- Nav height changes require updating scroll-padding-top everywhere
- Vercel auto-deploys on push but cache can be stubborn — always append `?v=N` to URLs
- Cream bar nav looks cheap; transparent floating nav with just logo + links is cleaner (v11)

## Additional Changes (later session)

- Menu links float without any pill background
- Scroll-padding reduced to 20px (no solid bar blocking content)
